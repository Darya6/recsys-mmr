# Адаптивный lambda в MMR for MovieLens-1M
#### Проект исследует адаптивный выбор параметра lambda в MMR-переранжировании рекомендаций при искусственном увеличении разреженности обучающих данных. 
#### Базовая модель — Implicit ALS; жанровое разнообразие оценивается через ILD.

### 1. Запуск в PyCharm
#### Требования
- Python 3.10 или 3.11.
- Архив MovieLens-1M с файлами ratings.dat, users.dat, movies.dat внутри ZIP.
#### Установка
- Откройте папку проекта в PyCharm.
- Создайте виртуальное окружение (Settings → Project → Python Interpreter).
- В терминале PyCharm выполните:
    ```
    python -m pip install --upgrade pip
    pip install -r requirements.txt
    ```

- Запустите main.py через кнопку Run или командой:
    ```
    python main.py
    ```
Первый запуск может занять продолжительное время: выполняется подбор
параметров ALS, сравнение адаптивных функций λ и оценка качества
рекомендаций при пяти уровнях сохранения обучающих данных.

### 2. Запуск эксперимента в Google Colab

### 3. Результаты
После выполнения результаты сохраняются в outputs/:

- als_grid_search_results.csv — подбор параметров ALS;
- adaptive_grid_search_results.csv — сравнение адаптивных функций lambda;
- sparsity_results.csv — метрики на каждом уровне разреженности;
- adaptive_grid_search_plot_ru.png — график валидационного подбора;
- f_tradeoff_plot_ru.png — сравнение стратегий по F_tradeoff@10;
- rating_distribution.png, user_activity.png — первичный анализ данных.
- Промежуточные разбиения, кандидаты и матрица сходства сохраняются в cache/. Чтобы принудительно пересоздать кэш, остановите программу и удалите соответствующие файлы из cache/. При изменении исходного набора данных старые кэш-файлы нужно удалить, иначе результаты могут не соответствовать новому набору.

### 4. Методика
- Пользователи с менее чем 5 оценками исключаются.
- Разбиение выполняется по времени отдельно для каждого пользователя: последние 20% наблюдений — тест, затем последние 10% оставшейся части — валидация.
- Положительными взаимодействиями для ALS считаются оценки >= 4.
- Активность для выбора lambda измеряется числом всех оценок в обучающей части.
- Для оценки используется фиксированный набор кандидатов: релевантные тестовые объекты и 200 случайных объектов, отсутствующих в исходной обучающей истории.
- Разреженность моделируется сохранением 100%, 70%, 50%, 30% или 10% обучающих оценок каждого пользователя.
- MMR использует нормализованную релевантность ALS и косинусное сходство one-hot векторов жанров.
- F_tradeoff@10 — используемое в проекте гармоническое среднее NDCG@10 и ILD@10.
